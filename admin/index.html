Accès

Demandes d’accès

Chaque demande prestataire, livreur ou admin doit être vérifiée avant approbation : contrôlez le code d’invitation que vous avez transmis à la personne, ou contactez-la directement. Un compte refusé n’a accès à rien.

Comptabilité

Compta & ajustements

Les revenus clients (prix des missions) ne bougent pas. Le bonus / malus ajuste séparément la paie du prestataire — par exemple un malus s’il a cassé quelque chose, un bonus pour un travail remarquable. Les totaux excluent les missions annulées.
